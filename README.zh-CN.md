# 轻译 · 个人免费 · 源码公开 AI 网页翻译工具

简体中文 · [English](README.md)

直接在网页里阅读译文。轻译是一款 Chrome 扩展，支持划选翻译和随滚动翻译网页，保留链接、字体与原有排版。个人非商业使用免费，商业使用需另行授权；API 调用费用由模型服务商收取。

## 两种翻译方式

| 模式 | 使用方式 | 当前支持 | 费用 |
|---|---|---|---|
| 网页会话 | 连接浏览器里已经打开并登录的 LLM 标签页，无需 API Key | DeepSeek 网页 | 轻译不收取 API 费用；受网站额度和使用规则限制 |
| 自带 API Key | 保存自己的 Key，直接调用模型服务商 | DeepSeek API，默认 `deepseek-flash` | 按服务商 Token 价格计费 |

豆包、更多 LLM 网页和可配置的 OpenAI 兼容接口属于后续规划，**当前版本尚不支持**。网页模式需要连接专用会话，翻译期间不要同时手动输入；网站改版可能影响适配。

## 安装与使用

需要 Chrome 120 或更新版本。可下载 [v2.9.0 扩展压缩包](https://github.com/leomeo360/qingyi-translator/releases/tag/v2.9.0)，解压后加载该目录；也可下载仓库，打开 `chrome://extensions`，启用开发者模式，点击“加载已解压的扩展程序”，选择 `extension/`，无需构建。

1. 打开扩展面板，连接已登录的 DeepSeek 标签页，或保存自己的 DeepSeek API Key。
2. 选中文字，按 `Alt+Shift+T` 或通过右键菜单翻译。
3. 阅读文章使用“翻译网页正文”；需要翻译导航和界面文字时使用“翻译全部可读内容”（`Alt+W`）。
4. 滚动时继续翻译；可通过进度控件取消或恢复原文，刷新也可恢复。

译文流式原位替换，不是上下对照双语显示。代码、路径、URL、输入框和敏感区域会尽力过滤；跨域嵌入页面需要授权。默认预翻译下方约两屏，可能消耗尚未阅读内容的 Token，可在高级设置关闭。

## 阅读体验：先等首屏，后续提前翻译

轻译优先翻译当前屏幕的正文，译文流式显示；首屏完成后，后台默认提前准备下方约两屏。**正常阅读并命中已完成的预翻译时，滚动后直接显示已有译文，无需再次等待模型生成。** 后台预翻译耗时不计入首屏等待时间，但产生的 Token 和费用仍计入总消耗。

| 体验指标 | 计时口径 | 当前证据 |
|---|---|---|
| 首屏开始显示译文 | 点击翻译 → 当前屏幕第一段实际绘制译文 | 尚未完成真实浏览器计时，暂不填秒数 |
| 首屏翻译完成 | 点击翻译 → 点击时首屏范围内的可译正文全部显示译文 | 尚未完成真实浏览器计时，暂不填秒数 |
| 滚动命中已预翻译内容 | 文字进入视口 → 缓存译文显示 | 无新增模型等待；历史模拟页记录为 82 ms，仅代表本地绘制调度 |

预翻译不是一次性完成所有剩余页面。快速滚动超过预取范围、网络较慢、预取失败或页面内容变化时，仍可能等待新翻译。此前约 4–5 秒的数据测量的是固定文本样本的 API 全部返回时间，**不是用户首屏等待时间**，已移至[独立技术报告](docs/API_SAMPLE_TIMINGS.md)，不用于评价首屏快慢。

后续首屏验收将固定浏览器、设备、网络、视口和页面，每站测十次，分别记录首段显示及首屏完成时间。保持默认预翻译配置，以“点击时的首屏范围”为完成边界，后台和离屏任务不延长该指标；另外记录滚动缓存命中率及未命中等待，避免把有条件的无等待写成所有情况下零等待。见[测试方案](docs/BENCHMARKS.md)。

## 实际消耗：100 次共 0.38 元

根据维护者提供的 DeepSeek 后台 22:00–23:00 账单，本轮费用为 **0.38 元人民币**。以下 Token 与 100 次测试、140 个 API 请求返回的用量逐项完全一致：

| 项目 | Token |
|---|---:|
| 总 Token | 220,199 |
| 输入：命中缓存 | 97,408 |
| 输入：未命中缓存 | 35,272 |
| 输出 | 87,519 |

输入总量为 132,680 Token（97,408 + 35,272）；220,199 是包含输出的总量，不是输入量。

按后台实际金额外推同等文本量及缓存结构：**平均每次 0.0038 元，每天 100 次约 0.38 元，30 天约 11.40 元**。这里包含失败尝试，不等于每天成功翻译 100 个完整网页，也不是仅翻译首屏的报价。页面长度、预翻译范围、缓存命中、重试及计费时段变化都会影响实际花费。

[DeepSeek 官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（2026-09-12 核对，`deepseek-flash`）：

| 每百万 Token | 空闲时段（元） | 高峰时段（元） |
|---|---:|---:|
| 输入：命中缓存 | 0.02 | 0.04 |
| 输入：未命中缓存 | 1.00 | 2.00 |
| 输出 | 4.00 | 8.00 |

高峰为北京时间周一至周五 09:00–12:00、14:00–18:00，其余为空闲时段。

`空闲时段估算（元）=（命中输入 × 0.02 + 未命中输入 × 1 + 输出 × 4）÷ 1,000,000`

按上述 Token 和公开单价算出 **0.38729616 元**，与提供的后台金额 0.38 元相差约 0.0073 元。Token 已完全对账，金额差异原因尚未核实，不推断为显示取整；实际支出采用后台报告的 0.38 元，每站表格保留单价估算并明确标注。

网页会话模式无法取得权威 Token 账单，应标为“不可获取”，不是零 Token。扩展高级设置当前仍导出原有美元费用估算；本文人民币账单核对不改变扩展内的计费显示，实际支出以服务商后台为准。

## 隐私与开发

Key 保存在本机扩展存储，由后台使用，网页内容脚本不能读取。两种模式都会将待译文字发送给 DeepSeek，网页模式会话还可能保留在服务商账号中。项目没有翻译中转服务器；敏感信息过滤无法保证识别所有情况，请留意待译内容。

```sh
npm test
npm run check
npm run package
```

开发建议使用 Node.js 20+ 和 Python 3。参见 [测试计划](docs/BENCHMARKS.md)、[历史测试报告](TEST_REPORT.md)、[版本说明](docs/HISTORY.zh-CN.md) 和 [贡献指南](CONTRIBUTING.md)。项目代码采用 [轻译个人非商业许可证](LICENSE)，不授予免费商用权，不属于 OSI 定义的开源软件；第三方测试素材保留原许可证，见 [第三方声明](THIRD_PARTY_NOTICES.md)。本项目与 DeepSeek、豆包无隶属关系。

# 轻译 · 免费的 Chrome 网页翻译插件

简体中文 · [英文版](README.md)

轻译是一款免费的 Chrome 网页翻译插件，支持一键网页翻译和划词翻译。点击网页右侧的“翻译”悬浮按钮，即可翻译页面上的全部可读内容。译文直接显示在原文位置，并保留链接、字体与排版。首屏优先翻译，后续内容提前准备，让外文网页读起来更轻松。

**免费使用，源码公开；商业使用需另行授权。**

## 两种方式，按需选择

| 翻译方式 | 如何使用 | 当前支持 | 费用 |
|---|---|---|---|
| 网页会话 | 使用 DeepSeek、豆包等网页版，不产生费用 | DeepSeek 网页 | 使用网页端免费额度，无接口调用费用 |
| 自带密钥 | 填入自己的接口密钥，直接调用模型，无需打开会话网页 | DeepSeek 接口 | 按模型服务商用量计费 |

目前已支持 DeepSeek 网页端，豆包等网页端将陆续接入，详见下方接入计划。

## 为网页阅读而设计

- **一键网页翻译**：网页右侧常驻操作条，点击“翻译”后立即处理当前屏幕，再次点击“原文”即可恢复。
- **简洁右键入口**：右键菜单只保留一个“翻译”，默认翻译页面上的全部可读内容。
- **划选即译**：选中文字，点击旁边的“译”或使用快捷键进行翻译。
- **原位显示**：译文流式替换原文，保留链接与页面样式，方便继续阅读和复制。
- **首屏优先**：先处理正在看的内容，不必等整篇文章翻译完。
- **整页预翻译**：首屏完成后，默认提前准备页面剩余内容；向下阅读时直接显示已经准备好的译文。
- **技术内容保护**：保留代码、网址、文件路径和字体图标，跳过输入框等区域。
- **随时恢复原文**：通过页面进度控件恢复，刷新网页也可还原。

预翻译范围可在高级设置中改为一至三屏或关闭。页面较长时，轻译仍会优先处理当前看到的内容。

## 安装与使用

需要 Chrome 120 或更新版本。

1. 下载并解压[最新安装包](https://github.com/leomeo360/qingyi-translator/releases/latest)。
2. 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的目录。
3. 打开扩展面板，连接已登录的 DeepSeek 专用会话，或保存自己的接口密钥。网页模式翻译期间，请保持专用会话不被手动编辑。
4. 点击网页右侧的“翻译”按钮，或在页面上点击鼠标右键并选择“翻译”。两种入口都会翻译全部可读内容，同时保留代码、特殊符号、网址和专有词。也可选中文字后按 `Alt+Shift+T` 进行划词翻译，按 `Alt+W` 翻译网页。

也可以下载本仓库，直接加载其中的 `extension` 文件夹，无需构建。Chrome 会提示授予普通网站访问权限，用于自动显示右侧操作条、读取待翻译文字并在原位显示译文。

## 隐私

接口密钥保存在本机扩展存储，网页内容脚本无法读取。待译文字直接发送给 DeepSeek，不经过本项目的中转服务器。网页模式的会话记录由服务商账号管理。

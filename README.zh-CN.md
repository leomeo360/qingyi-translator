# 轻译 · 个人免费，原位阅读外文网页

简体中文 · [英文版](README.md)

轻译是一款人工智能网页翻译扩展。选中一句话，或直接翻译网页正文，译文会出现在原文位置，保留链接、字体和排版。首屏优先翻译，后续内容提前准备，让阅读自然继续。

**个人非商业使用免费，源码公开；商业使用需另行授权。**

## 两种方式，按需选择

| 翻译方式 | 如何使用 | 当前支持 | 费用 |
|---|---|---|---|
| 网页会话 | 连接已经打开并登录的大模型标签页，无需接口密钥 | DeepSeek 网页 | 轻译不收取翻译费用，使用网站提供的额度 |
| 自带密钥 | 填入自己的接口密钥，直接调用模型，无需打开会话网页 | DeepSeek 接口 | 按模型服务商用量计费 |

豆包及更多大模型的接入正在规划中。

## 为网页阅读而设计

- **划选即译**：选中文字，通过快捷键或右键菜单翻译。
- **原位显示**：译文流式替换原文，保留链接与页面样式，方便继续阅读和复制。
- **首屏优先**：先处理正在看的内容，不必等整篇文章翻译完。
- **滚动预翻译**：首屏完成后，默认提前准备下方约两屏；滚动到已准备的内容时，直接显示译文，无需再次等待模型。
- **技术内容保护**：保留代码、网址、文件路径和字体图标，跳过输入框等区域。
- **随时恢复原文**：通过页面进度控件恢复，刷新网页也可还原。

预翻译范围可在高级设置中调整或关闭。快速滚动超出已准备范围时，轻译会优先翻译新的可见内容。

## 安装与使用

需要 Chrome 120 或更新版本。

1. 下载并解压[最新安装包](https://github.com/leomeo360/qingyi-translator/releases/latest)。
2. 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的目录。
3. 打开扩展面板，连接已登录的 DeepSeek 专用会话，或保存自己的接口密钥。网页模式翻译期间，请保持专用会话不被手动编辑。
4. 选中文字后按 `Alt+Shift+T`；阅读文章可点击“翻译网页正文”，翻译导航及界面文字可选择“翻译全部可读内容”或按 `Alt+W`。

也可以下载本仓库，直接加载其中的 `extension` 文件夹，无需构建。翻译跨域嵌入内容时，按提示授予对应网站权限即可。

## 隐私

接口密钥保存在本机扩展存储，网页内容脚本无法读取。待译文字直接发送给 DeepSeek，不经过本项目的中转服务器。网页模式的会话记录由服务商账号管理。

# Contributing / 参与贡献

Open an issue with the browser version, extension version, reproducible public URL,
expected behavior and actual behavior. Never include API keys or private page text.
Run `npm test` and `npm run check` for code changes. Update both READMEs for user-facing changes.
Discuss provider adapters before implementing them. Do not report mock timings as live LLM benchmarks.
Contributions are provided under this repository's LICENSE; no additional commercial relicensing rights are implied.

提交问题请附浏览器及扩展版本、可复现的公开网址、预期和实际表现。
不要上传 Key 或私人页面内容。面向用户的改动需同步更新中英文 README。
